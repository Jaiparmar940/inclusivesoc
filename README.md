# Inclusive Society — inclusivesoc.org

Static website for Inclusive Society, a 501(c)(3) nonprofit. Redesigned from the original WordPress site; hosted on GitHub Pages.

## Structure
- `index.html` — Home
- `projects/`, `about/`, `contact/`, `contribute/` — inner pages
- `assets/css/style.css` — shared stylesheet
- `assets/img/` — images carried over from the original site

## Custom domain
To point inclusivesoc.org here later: add a `CNAME` file containing `inclusivesoc.org`, then set the domain's DNS (A records to GitHub Pages IPs or CNAME to jaiparmar940.github.io) and enable it in repo Settings → Pages.
